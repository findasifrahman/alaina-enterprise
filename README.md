# Alaina Enterprise Website

Responsive single-page Vue/Vite website for Alaina Enterprise, an engineering company in Bangladesh providing passenger lift, lift spare parts, rooftop solar, generator, sub-station, electrical and construction support services.

## Features

- Sticky top navigation with highlighted phone number
- Responsive hero carousel
- Mission and vision section
- Animated stat counters
- Core services section with AI-generated elevator service image
- Four project showcases from `docs/Projects`
- Leadership team from `docs/team`
- SEO-focused FAQ content
- Contact section with address, phone, email and embedded map
- Gallery lightbox with full-screen backdrop
- Mobile bottom navigation with icons
- Footer logo, quick links, social links and developer credit

## Tech Stack

- Vue 3
- Vite
- @lucide/vue
- Plain CSS

## Commands

npm install
